# دخترِ ماه — نسخه نهایی آماده انتشار

این پروژه یک سایت فارسی با مسیر عمومی، مسیر مخفی رز و پنل سازنده متصل به بک‌اند Node.js است.

## محتویات
- `server.js` — سرور و API
- `package.json` — وابستگی‌ها و دستور اجرای سرور
- `public/index.html` — سایت و انیمیشن‌ها
- `public/assets/rose-photo.jpg` — عکس رز با برش برای قاب سایت
- `public/assets/rose-eyes.jpg` — عکس چشم‌های رز
- `.env.example` — نمونه متغیرهای محیطی

## مهم قبل از انتشار
این پروژه را فقط روی هاستی منتشر کن که **Node.js** را اجرا می‌کند. GitHub Pages به‌تنهایی نمی‌تواند سرور و پنل مدیریت را اجرا کند. رمز مدیر و کلید نشست را در تنظیمات خصوصی هاست وارد کن؛ هرگز آن‌ها را داخل فایل‌های سایت یا مخزن عمومی ننویس.

## تنظیمات ضروری هاست
- `ADMIN_PASSWORD`: رمز اختصاصی حداقل ۱۲ کاراکتری
- `SESSION_SECRET`: رشته تصادفی طولانی حداقل ۳۲ کاراکتری
- `NODE_ENV`: مقدار `production`
- `DATA_DIR`: مسیر پوشه‌ای که هاست اجازه نوشتن و نگهداری داده در آن می‌دهد
- Build command: `npm install`
- Start command: `npm start`

برای نگهداری آمار و تنظیمات بعد از راه‌اندازی مجدد، هاست باید فضای ذخیره‌سازی پایدار داشته باشد و `DATA_DIR` به آن اشاره کند. بدون فضای پایدار ممکن است داده‌ها پاک شوند.

## اجرای محلی (برای رایانه)
Node.js نسخه ۱۸ یا جدیدتر لازم است. دستورهای اجرا:

```bash
npm install
npm start
```

قبل از اجرای سرور، متغیرهای محیطی بالا را تنظیم کن. سایت به‌صورت پیش‌فرض روی `http://localhost:3000` اجرا می‌شود.

## پنل سازنده
از داخل سایت گزینه ورود به پنل سازنده را بزن و همان مقدار `ADMIN_PASSWORD` را وارد کن که در تنظیمات خصوصی هاست ذخیره کرده‌ای. رمز پیش‌فرضی داخل پروژه وجود ندارد.

## حریم خصوصی
برنامه نام مستعار، مسیر بازدید و آخرین مرحله را برای نمایش در پنل ذخیره می‌کند. برای گیت‌هاب از مخزن خصوصی استفاده کن و هیچ رمز واقعی یا فایل داده را آپلود نکن.


## صحنهٔ اختصاصی رز
- نمای چشم‌های رز قبل از شروع بازی نمایش داده می‌شود.
- پس از مراحل داستان، جعبه با انیمیشن باز می‌شود؛ لیلیوم‌ها شکوفا می‌شوند و حلقه بعد از آن ظاهر می‌شود.
- سپس صحنهٔ ورود نمادین سیروس، بوسهٔ سینمایی و نامهٔ پایانی نمایش داده می‌شود.
- عکس‌های واقعی داخل `public/assets/` قرار دارند. عکس پرتره با برش ساده آماده شده؛ پس‌زمینهٔ عکس به‌طور کامل حذف نشده است.

## موسیقی مسیرها
- با ورود به مسیر عمومی، موسیقی بی‌کلام فانتزی «Emotional Fantasy Background Music» پخش می‌شود.
- با ورود به باغ مخفی رز، آهنگ «عشق کمیاب» از گوگوش در پخش‌کنندهٔ YouTube نمایش داده می‌شود.
- پخش آنلاین است و برای شروع ممکن است نیاز به لمس دکمهٔ پخش داشته باشد؛ بررسی شرایط مجوز موسیقی پیش از انتشار عمومی بر عهدهٔ منتشرکننده است.
